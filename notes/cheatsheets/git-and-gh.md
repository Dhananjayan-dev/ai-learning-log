# Git and GitHub CLI cheatsheet

| Task | Command |
|------|---------|
| Status | `git status` |
| Save work | `git add . ; git commit -m "message"` |
| Upload | `git push` |
| New branch | `git switch -c feature-name` |
| Open a PR | `gh pr create --fill` |
| Open repo in browser | `gh repo view --web` |
| New project repo | `gh repo create NAME --public --clone --add-readme` |
