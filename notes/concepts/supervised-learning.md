# Supervised learning

**One line:** learn a mapping from inputs (features) to a known answer (label) using past examples.

- Regression: the label is a number (job runtime in minutes).
- Classification: the label is a category (job fails or succeeds).
- Always judge a model on data it has not seen (train/test split).

**Data-engineering analogy:** features are the columns of a well-modelled fact table; the label is the column you wish you had in advance.
